Krita统计插件 — 安装使用说明

安装步骤

Installation Steps

  1. 解压 ZIP
    Extract the ZIP archive.
  2. 复制到 pykrita 目录
    Copy these two items into Krita's pykrita/ folder:
    • krita统计插件.desktop
    • krita统计插件/（整个文件夹 / entire folder）
    Windows：%APPDATA%\krita\pykrita\
    Linux：~/.local/share/krita/pykrita/
    macOS：~/Library/Application Support/krita/pykrita/
  3. 启用插件
    Launch Krita → Settings → Configure Krita → Python Plugin Manager → check Krita统计插件 → Apply → Restart Krita.
  4. 打开面板
    Go to Settings → Dockers → enable Krita统计插件.

使用方法

Usage

  • 排序：顶部下拉切换 创建/修改时间 升/降序
  • 浏览：点击 📁 选择扫描目录
  • 搜索：第二行输入框实时过滤文件名
  • 折叠：点击年/月标题展开或收起
  • 详情：点击卡片查看图像信息和作者联系方式
  • 图表：📊 打开统计图表对话框
  • 导出：📤 生成 HTML 报告（含图表、缩略图、可排序表格）
