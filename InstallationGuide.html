Krita Statistics Plugin — Installation Guide

Installation Steps

  1. Extract the ZIP archive.
  2. Copy into Krita's pykrita/ folder:
    • krita统计插件.desktop
    • krita统计插件/ (the whole folder)
    Windows：%APPDATA%\krita\pykrita\
    Linux：~/.local/share/krita/pykrita/
    macOS：~/Library/Application Support/krita/pykrita/
  3. Launch Krita → Settings → Configure Krita → Python Plugin Manager → check Krita统计插件 → Apply → Restart.
  4. Go to Settings → Dockers → enable Krita统计插件.

Features

  • Scan .kra files and display as an album gallery
  • Sort by creation / modification time (ascending / descending)
  • Collapsible year → month → day groups
  • Real-time filename search
  • Browse any folder for .kra files
  • Click card to view image info & author contacts
  • Statistics chart dialog (7d / 30d / 12m / all, bar/line/curve)
  • Export HTML report with charts, thumbnails, and sortable table
  • Cache system for fast re-scan
  • Settings persist across restarts
